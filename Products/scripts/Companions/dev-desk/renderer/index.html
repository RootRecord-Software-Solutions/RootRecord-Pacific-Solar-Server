Desk startup

      
      
      


      
Projected start

      
Auto-fills from the rolling average of first daytime starts (after sunrise, before 2pm). Save to lock a manual time; Use average to follow the average again.

      

        
        
      

      

        
        
        
      

      


      
Projected shutdown

      
Nightly HST time: Ava posts a shutdown report to Discord + Slack, runs /rootstop on Minecraft, then powers herself off. Typical window ~10pm–1am.

      

        
        
      

      

        
        
        
      

      


      
Ops schedule banner

      
Shown on the local status board. Auto-shows when the site bank has about 3 hours left — Starlink goes dark; the Root Server can keep offline tasks on its own battery. Not painted on the cold holding page.

      
      
      
      
      

        
        
      

      


      
RootRecord governance

      
Same idea as the RootMC constitution: people speak, daily tally, majority can pass a proposal. Notes about people always save. These two switches turn the community program and the self-update / Cursor hook on or off. Self-update waits at least an hour after boot reports. Cursor stays queued unless remaining context is known and above the floor (default 25%). Unknown context never auto-runs.

      
      
      

        
        
      

      

        
        
        
      

      


      
API prices and balances

      
Public list prices are pulled at boot and every morning (docs pages only — no tokens). Prepaid APIs stay unknown until you seed a starting dollar amount. Cursor is a monthly pool (percent). Spend master and every vendor stay off until you turn them on. Grok has its own plans — leave it off.

      
      
      

        
        
      

      

        
        
      

      
      
      
      
      

        
        
      

      

      


      
Service disruption

      
Optional banner on the public status / solar page. Shown only when enabled. Set a clears-on date (HST) for a live countdown — storms can be multi-day (next sunny morning, end of maintenance, etc.).

      
      

        
        
      

      
      

        
        
      

      

        
        
      

      
Leave the date empty for no countdown. Time defaults to 10:00 HST (typical sunny start) if you only pick a day. GFS can fill the next sunny / calmer morning — you still save to publish.
