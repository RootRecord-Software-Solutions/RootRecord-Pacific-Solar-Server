Knowledge

The knowledge layer holds architecture, procedures, agent context, security material, work orders, and guides. It is the RootRecord Library. A repository existing is not a runtime health signal. Knowledge

Runtime

Runtime does the work. Pacific Solar Server is that runtime. Field systems sit with Hawaiʻi. Computation and services continue on the Mainland Server. The public network feed can show that this path is reporting. It does not grade the whole runtime. Infrastructure · Systems

Data

Data keeps the state. The RootRecord Database is that layer: telemetry, environmental records, logs, and retained system state. This site has no public database health signal. Field readings are observations, not a database score. Data

Network

The Root Record Network joins Hawaiʻi and the Mainland Server. Public status uses that link. Private paths are not part of this page. Status

Continuity

The layers stay separate so the system can still be understood after people, agents, and machines move on. Meaning stays in knowledge. Work stays in runtime. State stays in data. Why Root Record exists

Verification

A page, a commit, or a configured service is not proof that a runtime is healthy. State is accepted when there is evidence for it. Security
