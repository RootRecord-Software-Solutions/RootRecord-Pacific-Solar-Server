Trust

Security

Security is part of the system from the beginning. This page describes how Root Record treats that for customers. It does not publish addresses, host names, credentials, or private endpoints, and it does not offer a security score.

Security

People, services, and automated tools reach a system through a boundary that matches the work. Reading a public page is not the same as operating a system. A public page cannot start, stop, or change a field system.

A claim, a commit, or a command is not evidence by itself. State is accepted when there is something to check. Shipping a change and proving the running system took that change are separate steps.

Privacy

Handle information intentionally and minimize unnecessary exposure. The public site may describe products, services, and public readings. If a detail is not clearly public, it is left out.

The public names for where systems run stop at Hawaiʻi and the Mainland Server, linked as the Root Record Network. A finer location, a host name, or a private route is not part of this site.

The full Privacy Policy covers accounts, apps, payments, and deletion. Use of the Services is covered by the Terms of Service. A request that keeps the account is on data deletion.

Operations

Build, monitor, maintain, and improve the systems people depend on. Important operations stay understandable: what the change was for, where it applies, and how someone can tell whether it took effect. Those operator paths are not listed here.

Written field and operations reports stay available as published records. Reports · Field readings

Status

See the current public operational state where live reporting is available. A row is filled only when the public feed returns a value. This site does not fabricate uptime, traffic, server counts, energy totals, user counts, or certifications.
