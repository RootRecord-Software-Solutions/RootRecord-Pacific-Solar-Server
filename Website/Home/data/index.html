Data layer

Root Record data

The data layer is persistent system state. The RootRecord Database is where that state lives. This page names the kinds of record. It does not publish a schema, credentials, or an internal layout. There is no public runtime signal for the database itself.

Telemetry

Measurements reported by field systems and the network.

System state

The retained picture of what the system last knew.

Energy

Generation and storage readings from the physical plant.

Weather

Environmental observations used as operating context.

Geology

Volcanic and seismic context for the Hawaiʻi site.

Media

Captured records that belong with an operation.

Logs

What the system did, kept so it can be checked later.

Reports

Summaries assembled from retained state.

  • Telemetry

    Telemetry is a measurement with a time. On the public site that means network counts, River and Delta power values, the weather observation time, and the Kīlauea status. A missing measurement stays missing. The site does not draw a history when the feed has no series.

  • System state

    System state is the retained picture of what the system last knew. The public pages show the last observation they were given. They do not show internal state files, process lists, or a database score.

  • Energy

    Energy is generation and storage from the physical plant. The public values are current state of charge, solar input, AC output, and USB-C output for River and Delta, when those fields are present. Daily totals and a power history are not in the public feed.

  • Weather

    The public weather record is an observation time and the fact that a Hawaiʻi report exists. Temperature, humidity, pressure, wind, and precipitation are not in that feed, so the operations page omits them. A written forecast, when one is published, lives on Reports.

  • Geology

    Geology on the public feed is the Kīlauea status: alert level, color code, headline, and whether an eruption is indicated. That is context for the Hawaiʻi site. It is not a health light for the computers.

  • Media, logs, and reports

    Media and logs stay in the data layer so an operation can be checked later. They are not dumped onto this website. Reports are the public summaries. The latest text for each desk is linked from Reports. A report is not a live query of the database.

What this site will not claim

There is no public runtime signal for the database itself. Field readings are observations, not a database health score. Uptime, row counts, and replication state are omitted because they are not in the public feed.

The public database repository is the published face of the layer. It is not the running store. Status · Systems · Ecosystem · Public database repository
