Built from Hawaiʻi

Root Record is built from Hawaiʻi. Field systems and the Pacific Solar Server operate there. The Mainland Server is the other public side of the runtime. The Root Record Network is the link between those two sides. Distance, power, weather, and connectivity are engineering constraints in the system, not a backdrop.

Why Root Record exists · Infrastructure

Built for continuity

Understandable

Systems should retain enough context to be understood by the people and agents operating them.

Verifiable

A commit is not proof of deployment. A command is not proof of execution. System state requires evidence.

Repairable

Systems should retain enough history and context to be operated, migrated, and repaired without starting from zero.
