Root Record Network

Infrastructure

Root Record runs across a real distance. Field systems and the Pacific Solar Server are in Hawaiʻi. The Mainland Server carries computation and services on the other side of the Root Record Network.

  1. Hawaiʻi
  2. Field systems
  3. Root Record Network
  4. Mainland Server
  5. Computation and services

  • Hawaiʻi

    Hawaiʻi is an operating site, not a backdrop. Power, weather, geology, and the machines that measure them are part of the system. The Pacific Solar Server is the runtime that lives with those constraints. Distance and connectivity are design inputs, not scenery.

    The public field systems there are River, Delta, the weather record, and Kīlauea. Each is shown on Systems only when the feed has a reading.

  • Mainland Server

    The Mainland Server is the other public side of the runtime. It continues computation and services when the work has to cross the network. The public name stops there. This page does not name a city, a provider, a host, or an address.

    A flow count for the Mainland Server, when the feed has one, means the public network poll reported that count. It does not describe what those flows are carrying.

  • Website Node

    The Website Node is the public site. It presents Root Record. It does not run the field systems, and it does not hold the database. The globe draws it as its own point, with architectural arcs from Hawaiʻi and the Mainland Server.

    Those arcs are not counted as live traffic. Seeing this website is evidence that the page loaded. It is not evidence that the runtime is healthy.

  • Communications

    The Root Record Network is the link between Hawaiʻi and the Mainland Server. Public status uses that link: active flows, endpoints, and the two sides. Private paths, tunnel names, and internal routes are not published here.

  • Physical systems

    Generation, storage, sensors, and the structures around them produce the energy and environmental record. River and Delta report state of charge, solar input, and output when the feed has those values. Weather on the public feed is an observation time, not a sensor panel. Kīlauea is a geological status, not a site health light. Energy

  • Network architecture

    The public shape is Hawaiʻi, field systems, the network link, the Mainland Server, and the Website Node as the presentation layer. Endpoints on the live globe are places the feed can name. They are not a map of private hosts.

  • Resilience

    The split exists because distance, power, and connectivity fail independently. One side should be able to keep a bounded part of the work alive when the other side is limited. The public page does not claim that failover has been proven. It only describes why the split is there.

  • Continuity

    Infrastructure is there so the system can be understood, checked, and repaired later. State belongs in the data layer. Meaning belongs in the knowledge layer. The machines belong to the runtime. Continuity · Data · Knowledge
