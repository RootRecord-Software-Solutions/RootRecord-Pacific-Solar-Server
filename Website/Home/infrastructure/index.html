Root Record Network

Infrastructure

Root Record runs across a real distance. Field systems and the Pacific Solar Server are in Hawaiʻi. The Mainland Server carries computation and services on the other side of the Root Record Network.

  1. Root Record Network
  2. Hawaiʻi
  3. Field systems

  5. Mainland Server
  6. Computation / services

  • Hawaiʻi infrastructure

    Hawaiʻi is an operating site, not a backdrop. Power, weather, geology, and the machines that measure them are part of the system. The Pacific Solar Server is the runtime that lives with those constraints.

  • Mainland Server

    The Mainland Server is the other public side of the runtime. It continues computation and services when the work has to cross the network. The public name stops there. Finer geography is not part of the site.

  • Communications

    The Root Record Network is the link between Hawaiʻi and the Mainland Server. Public status uses that link. Private paths, addresses, and credentials are not published here.

  • Physical systems

    Generation, storage, sensors, and the structures around them produce the energy and environmental record. Readings are shown only when a field system reports them. Energy

  • Network architecture

    The public shape is Hawaiʻi, field systems, the network link, the Mainland Server, then computation and services. Endpoints on the live globe are places the feed can name. They are not a map of private hosts.

  • Resilience

    The split exists because distance, power, and connectivity fail independently. One side should be able to keep a bounded part of the work alive when the other side is limited.

  • Continuity

    Infrastructure is there so the system can be understood, checked, and repaired later. State belongs in the data layer. Meaning belongs in the knowledge layer. Continuity
