RootRecord Library

Durable knowledge

The RootRecord Library is the knowledge layer. It holds the record of how the system is built and run, so people and agents are not starting from a blank session.

  • Agent context

  • Security

Code should have a home. Data should have a home. Knowledge should have a home.
