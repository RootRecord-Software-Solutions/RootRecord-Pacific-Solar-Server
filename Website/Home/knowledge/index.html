The split

Code is the runtime, on the Pacific Solar Server and the Mainland Server. Data is the RootRecord Database. Knowledge is the RootRecord Library. Mixing them makes the next session guess which fact is a procedure, which fact is a measurement, and which fact is a running process.

This page explains that split. It does not publish private library material. Ecosystem · Intelligence · Security

Continuity

The knowledge layer lets the system keep its understanding across interactions and operational changes. A new session can start from the record instead of from memory. That is the point of separating knowledge from the runtime and from the database.

A public page can name the categories. It cannot stand in for the library. If a procedure is not published here, it is not public.

What is public

The public library repository is the published face of the knowledge layer. This website explains the architecture in public language: Hawaiʻi, the Mainland Server, the Website Node, the Root Record Network, and the three layers.

Private notes, operator procedures, and internal names stay out of these pages. A file existing in a repository is documented. It is not a live service. Public library repository
