Automation

Automation is the part of the runtime that repeats bounded work. Collectors read field systems. Schedulers decide when a pass runs. The result is handed to the data layer as a reading, not as a story about the reading.

This page does not publish a task queue, a job count, a success rate, or a list of what ran. No public signal is available for that queue. A collector being configured is not the same fact as a current value above.

Monitoring

Public monitoring is the status feed. A reading is present, stale, offline, or absent. The page does not turn a loaded document into a healthy system.

  • Live A successful poll returned counts, and that poll is recent.
  • Stale A later poll failed, and the last reading is still on the page.
  • Offline This browser reports that it is offline.
  • No public signal The feed has no count or reading to show.
  • No reading That field is in the model, and the feed did not return a value.

Status uses the same words.

Reporting

Two public surfaces exist. This page and Status show current observations: energy, the weather observation time, Kīlauea, and network counts. Reports holds the latest written field and operations readings.

A report is a published text. It is not a second live feed, and it is not a history chart. If a report page says nothing is on file, that is the current public state. Power over time is still not in the operations feed, so it is not charted here.

Verification

Verification is the check that the feed actually reported a value, with a time. A configured collector, a commit, or a page that rendered is not that check.

Energy is treated as stale when the observation is old. Weather and geology use longer windows, because those records are not sampled on the same cadence as power. The exact window is a display rule. It is not a claim that the instrument failed. Security · Data
