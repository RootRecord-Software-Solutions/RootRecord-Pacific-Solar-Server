Automation

Automation is the part of the runtime that repeats bounded work: collection, scheduling, and handoff between field systems and the record. This page does not publish a task queue or a job count. No public signal is available for that queue.

Monitoring

Public monitoring is the status feed. A reading is present or it is not. The absence of a reading is not filled with a healthy state. Status

Reporting

Public observations are the current energy, weather, geology, and network readings above. They are last-known values from the public feed. There is no public history table to expand.

Verification

A configured collector is not the same fact as a current reading. Verification is the check that the feed actually reported a value, with a time. Security · Data
