Intelligence

Root Record treats intelligence as part of the system architecture rather than a standalone interface. Agents operate with persistent context, controlled execution, and verifiable results.

  2. Agent
  3. Decision

  • Agents

    Agents take responsibility for bounded work: reading context, proposing a next step, and carrying that step through the controls that apply to it. An agent is an operator inside the system, not a separate product surface.

  • Persistent context

    Knowledge has to survive a single interaction. Architecture, procedures, and prior decisions stay in the knowledge layer so the next person or agent can see what the system already learned. Knowledge

  • Controlled execution

    Actions pass through the boundary that fits the operation. Control is the point where a decision becomes an allowed action. Unrestricted execution is not the model.

  • Verification

    Execution should produce evidence. A statement that something ran is not the same record as the result. Verification is how the system accepts state. Security

  • Human oversight

    Important operations stay understandable and controllable by people. Agents can prepare and perform bounded work. People remain able to see the context, the control, and the evidence.
