This page is the public feed, not a health score. A row is filled only when that feed returns a value. Core services use a smaller vocabulary: documented, reporting, or no public signal. A green mark is used only when the network poll is live.

  • Live The network poll succeeded and is recent.
  • Stale A later poll failed. The last reading is still shown.
  • Offline This browser reports that it is offline.
  • No public signal The feed did not return that fact.
  • No reading The field is expected, and no value arrived.
  • Documented The layer is described. That is not a runtime claim.
  • Reporting A public feed is answering for that layer.
